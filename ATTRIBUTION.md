# Open-Source & Responsible AI Attribution (Hackathon Rules 5, 6, 7 & 10)

- **FastAPI & Uvicorn (MIT License):** Asynchronous REST API gateway.
- **ChromaDB (Apache 2.0 License):** Local persistent vector embeddings database.
- **SQLite3 (Public Domain):** Relational Electronic Health Record (EHR) and mass-casualty triage queue storage.
- **Google Gemma 3 1B (`gemma3:1b` via Ollama):** Local edge inference model used strictly on top of deterministic clinical safety gates.
