# 🚑 LifeLine AI v11.0 — Enterprise Offline Emergency, Trauma & Clinical RAG Suite

## 🏗️ 15-File Modular Microservice Architecture
- `main.py` — FastAPI REST Gateway & Static Asset Server
- `config.py` — Centralized Environment & Path Configuration
- `knowledge_base.py` — 22 Verified WHO Protocols, Drug Contraindication Matrix & 4-Language Phonetics
- `clinical_engine.py` — Hospital NEWS2, ICU Shock Index, Glasgow Coma Scale (GCS) & Parkland Burn Formula
- `rag_engine.py` — 128-Dim Semantic Vector Embeddings & ChromaDB Engine
- `database_ehr.py` — SQLite3 Persistent Hospital EHR & Mass-Casualty Queue
- `voice_engine.py` — 4-Language Studio MP3 Synthesizer & Local Disk Cache (`./lifeline_voice_cache/`)
- `cli_rescue.py` — Low-Power Command-Line Interface for Disaster Field Rescuers
- `test_suite.py` — Automated Unit & Integration Test Suite
- `static/index.html`, `static/styles.css`, `static/app.js` — 6-Tab VisionOS Glassmorphism Frontend
